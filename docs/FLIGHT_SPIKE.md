# Второй playable spike: западный аэропортовый этап

Основной экран — `web/flight/index.html`, задача #24. Старт: Пулково,
1 августа 2026 20:00 UTC, 30 т на борту, конечные склады по 64 т.
Цель — Толмачёво после обязательного обслуживания. Профиль, Солнце, скорость
и условия [проверенного этапа](ACADEMIC_WESTWARD.md) сохранены.

## Играть

Поверните глобус и приблизьте область, выберите аэродром и нажмите «Полёт».
Выбор/навигация не расходуют UTC. Дозаправка под выбранный рейс, отправление,
полёт и обслуживание выполняются автоматически; на паузе показано фактическое
промежуточное состояние. Кнопка «Центрировать» возвращает самолёт, сохраняя масштаб.

Основной проверочный путь: Пулково → Кефлавик → Эдмонтон → Анадырь → Толмачёво.
Он нужен для регрессии, а не является единственно разрешённым прохождением:
расчётом подтверждены альтернативные западные цепочки. Прямой восточный рейс
блокируется Солнцем; искусственного запрета направления нет.

Итог различает достижение цели, Солнце и подтверждённое отсутствие перелётов.
Он показывает цель, UTC, длительность, пройденный путь, посадки, топливо и список
посещённых аэропортов. Неоконченная проверка или неопределённость не означают проигрыш.

## Сохранение и журнал

В верхнем меню «Партия» доступны сохранение/восстановление в браузере,
экспорт журнала, загрузка файла и новая партия. На телефоне меню обозначено
SVG с тремя точками; оно доступно с клавиатуры и закрывается Escape.

Прогресс сохраняется при подтверждении/паузе рейса, окончании перехода и исходе,
периодически во время воспроизведения (раз в 2 секунды), при скрытии страницы
и `pagehide`. При обычной перезагрузке возвращаются сохранённые UTC, принятый
маршрут и остатки складов. Продолжение всегда начинается **на паузе**: закрытая
страница не расходует игровое время. При продолжении принятого рейса камера снова
следует самолёту; ручная навигация освобождает её. При аварийном завершении без lifecycle-событий
может потеряться прогресс после последнего checkpoint.

Используется localStorage текущего origin с ключом `into-the-night-flight-v3`.
Он не является облачным сохранением: очистка данных браузера удаляет его,
а другая вкладка того же origin может заменить checkpoint. Для переноса партии
или надёжной копии экспортируйте файл. При запрете/переполнении хранилища игра
продолжается и сообщает об ошибке в меню; экспорт файла остаётся доступен.

Журнал — тот же переносимый формат `into-the-night-mission`, версия 3, который
создаёт `MissionSession.save()`: определение и версии мира/профиля, seed,
принятые назначения, UTC-курсор, наступившие события и снимок состояния.
Второго формата или расчёта истории в UI нет. Лишь выбранный, но не принятый
аэродром планирования не является частью сохранения; активное назначение
восстанавливается из принятого рейса. Камера возвращается к фактической позиции.

Повреждённый/несовместимый файл не заменяет текущую сессию или намерение playback.
При несовместимом локальном сохранении новая страница сообщает об ошибке
и не перезаписывает исходный файл автоматически: явное сохранение или новая
партия заменяет его. Загрузка разрешена только для текущего определения миссии;
старые mission v1/v2 и исторический survival явно несовместимы.

## Воспроизведение

```sh
npm ci
npm run dev
# Либо:
npm run build:web
npm run serve:web

# Экспортированный браузером журнал:
node scripts/mission-cycle-cli.mjs --load /path/to/into-the-night-mission-journal.json
# Закончить текущий принятый переход, не выбирать следующий автоматически:
node scripts/mission-cycle-cli.mjs --load /path/to/into-the-night-mission-journal.json --resume
```

CLI восстанавливает тот же курсор и события; для no_routes возвращает exit 3,
для обычной/победной партии — 0. Контроль всех ресурсов доступен в сохранении;
вывод CLI, как прежде, сокращает склады до посещённых аэропортов.
Перенос Chrome ↔ Node допускает только финальные числовые разряды снимка:
≤1e−9 кг/км для топлива/запасов/расстояния и ≤1e−10° для координат.
UTC, события, результат, версии и checksum проверяются строго. Состояние
пересчитывается ядром; этот допуск не изменяет физику или солнечные границы.

## Проверки и рецензия

`npm run check` включает восстановление круиза/дозаправки, неизменность партии
при отказе, принятое направление/след и прежний темп playback, переносимость
числового снимка и отказ при существенном повреждении.
`npm run test:browser` включает настоящий desktop/touch-ввод, reload и файловую
загрузку, локальное восстановление, ошибку localStorage, проигрывание браузерного
журнала через CLI, полный западный маршрут, итог и перезапуск. Набор повторяется
на `/into-the-night/release/0.1.0/`; на mobile дополнительно проверяется 320 px.
Снимки `spike-result-*` входят в артефакт `globe-previews`.

Автоматическая готовность не заменяет финальную рецензию владельца. В #24 остаётся
получить отзыв на эту сборку: стало ли проще выбирать/лететь, чувствуется ли
мировой масштаб, интересен ли выбор посадок и понятны ли причины блокировок.
Ранее владелец сообщил «смог добраться до Новосибирска. Уже играбельно»;
это отзыв о предыдущей сборке, а не о новых сохранениях.

Еда, ручное ожидание, наземное получение знаний и сезонные главы не включены.
Ожидание #25 — после рецензии и согласования управления. Первоначальный
[survival spike](PLAYABLE_SPIKE.md) остаётся историческим, на `web/index.html`.
