# Первый этап: из Петербурга в Новосибирск на запад (#21)

Конфигурация первого аэропортового playable-этапа — [academic-westward-v2.json](../data/scenarios/academic-westward-v2.json): **Пулково, 1 августа 2026 20:00 UTC, 30 т топлива на борту**, цель — Толмачёво после обязательного обслуживания. Склады всех 1183 аэропортов конечные, по **64 т**. Дозаправка перед выбранным рейсом, резерв 5 т, без еды и ручного ожидания. Профиль B788-reference-v1, координаты и Солнце не изменены; новые аэропорты не понадобились.

Это выбор конфигурации для рецензии через PR; merge выполняет владелец. После merge она становится стартом браузера и CLI. Прежние южный контроль и исторические отчёты сохранены отдельно.

## Подтверждённый западный маршрут

**Пулково → Кефлавик → Эдмонтон → Анадырь → Толмачёво**, 16447.274 км, четыре рейса, три дозаправки, 23 ч 41 мин 06 с физического времени. Цель восточнее старта на 52.356°, но суммарная развёрнутая долгота маршрута **−307.644°**: путь проходит Атлантику, Северную Америку и линию перемены дат. Это обход на запад, не прямой перелёт в Сибирь и не сокращённый масштаб Земли. Более короткая длина, чем у экваториального круга, следует из реальных северных широт.

На финише 5000 кг на борту. Остатки использованных складов: BIKF 35294.900 кг, CYEG 36612.302 кг, UHMA 30185.515 кг; склады ULLI и UNNT остаются по 64000 кг. В отчётах `stockChangesKg` — новые остатки изменённых складов, а не арифметические дельты. Полные точные значения и времена с дробными миллисекундами сохраняются в JSON; таблица округлена для чтения.

Полная последовательность каждого рейса, включая исходную заправку и обслуживание назначения, проверена общим непрерывным решателем с допуском 0.05 с; повтор обычными параметрами и MissionSession даёт те же UTC/топливо/склады. Отображение и скорость анимации не участвуют в доказательстве.

## Выбор маршрутов и даты

В ограниченном наборе цепочек найдено **25 безопасных финишей** с **семью первыми направлениями**: Кефлавик, Дублин, Манчестер, Осло, Стокгольм, Копенгаген и Гамбург. Через Камчатку также проходит вариант ULLI → BIKF → CYEG → UHPP → UNNT: 17809.234 км, финиш 2 августа 21:26:03 UTC. Игрок не обязан повторять расчётный путь, каталог и физика не ограничиваются этими цепочками.

Перебраны явные списки 15 первых пунктов, 7 североамериканских и 6 азиатских промежуточных пунктов, с фильтром пригодности текущего профиля; состав и параметры записаны в `ACADEMIC_SETTINGS`. На сетке одинаковых стартов 20:00 UTC 13 июля нет цепочки в этом наборе, 20 июля — 7 / 2 первых направления, 25 июля — 10 / 2, 1 августа — 25 / 7. Это причина выбора более вариативного старта 1 августа, а не доказательство, что до него маршрутов вообще нет. Отдельные первоначальные пробы и неполные поиски не выдаются за исчерпывающий результат.

Прямой восточный ULLI → UNNT попадает на Солнце в крейсерской фазе. Проверены также **все 1181 возможный единственный промежуточный аэропорт**: допустимого двухрейсового пути в текущем каталоге/профиле при фиксированных условиях нет, неопределённых результатов нет. Трёхрейсовые и иные более длинные пути целиком не исключались. Направление не запрещено кодом.

Для Шпицбергена (ENSB) и Северного полюса непрерывно подтверждён полярный день на всех UTC-сутках прохождений — 1 и 2 августа. Это не утверждение о любой северной широте: западные маршруты используют реальную ночь южнее полярной дневной зоны. Прежний безопасный прямой августовский расчёт остаётся исключённым контрольным примером; новый августовский старт выбран именно для западного обхода.

## Прибытие и следующая глава

В основном варианте готовность в Новосибирске **2 августа 19:41:06 UTC**, следующий геометрический восход около **22:48:12 UTC** — примерно 3 ч 07 мин ночи. Из фактически унаследованных UTC, топлива и складов есть **247 безопасных немедленных следующих рейсов**, но прямой рейс в Токио солнечно опасен. Анадырь выбран основным примером ради более раннего прибытия: вариант через Камчатку оставляет только 17 немедленных направлений.

**15 из 25 более поздних безопасных финишей не оставляют ни одного немедленного следующего рейса.** Для каждого пути это отдельно записано в routes.json. Безопасный аэропортовый финиш не доказывает продолжение кампании. Для этой первой миссии цель — закончить аэропортовый этап; пригодность ветвей для полной кампании и получение знаний проверяются в #31.

Наземная поездка в Академгородок, длительность передачи данных и полная цепочка в Японию **не включены** в это доказательство. `knowledgeTransferSeconds: null` означает, что время ещё не определено; это не скрытое мгновенное получение знаний. Ожидание не добавлено как обход опасности. Япония/Антарктида/Австралия/Шпицберген/бункер и три части знания остаются планом [CAMPAIGN.md](CAMPAIGN.md).

## Воспроизведение

```sh
npm run build
npm run research:academic
npm run validate:academic
npm run mission:cycle -- --path examples/academic-westward/iceland.json
npm run mission:cycle -- --path examples/academic-westward/oslo.json
npm run mission:cycle -- --path examples/academic-westward/copenhagen.json
npm run mission:cycle -- --path examples/academic-westward/kamchatka.json
# Ожидаемый отказ (exit 2), исходное состояние неизменно:
npm run mission:cycle -- --path examples/academic-westward/direct-blocked.json
# Старый южный контроль требует явного определения:
npm run mission:cycle -- --definition data/scenarios/westward-control-v2.json --path examples/mission-cycle/christchurch.json
npm run check
npm run test:browser
```

Отчёты: [метаданные, SHA-256, дата/сокращения/полярный день](academic-westward/report.json), [все 25 цепочек](academic-westward/routes.json), [основной свидетель, фазы и журнал](academic-westward/witness.json), [унаследованное продолжение](academic-westward/continuation.json). Обновление эталона — только явным `npm run research:academic -- --write` с просмотром diff. Числа не зависят от часового пояса процесса; CLI проверяется также в Asia/Novosibirsk.

Профиль самолёта и pinned OurAirports `11e4de2834aff6ab54c1f8fc89b8679ea3d08418` прежние. Геометрический отбор полос не равен эксплуатационному разрешению Boeing. Прежние исследования JFK, августовского прямого рейса, южного контроля v1/v2 не перезаписаны и продолжают сверяться собственными командами. Сохранения не меняют сценарий молча: старый контроль восстанавливается со своим определением, ожидаемое новое определение его отклоняет.
