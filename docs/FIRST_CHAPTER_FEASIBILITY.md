# Санкт-Петербург → Новосибирск: проверка первого этапа (#21)

**Уточнение цели владельцем:** нужен западный обход Земли с несколькими дозаправками; назначение восточнее старта выбрано именно для этого. Приведённый ниже безопасный прямой августовский рейс исключён из кандидатов. Его расчёт сохранён как контрольный пример неподходящей постановки; это не прохождение и не предлагаемая первая миссия. Актуальная проверка обхода — [westward.json](campaign-research/westward.json), воспроизведение `node scripts/westward-research.mjs --verify`. Опасность прямого рейса и северного сокращения должна следовать из Солнца, а не из искусственного запрета направлений.

Прямой ночной перелёт **Пулково (ULLI) → Толмачёво (UNNT)** возможен в reference-модели 20 августа 2026. Проверены весь полёт и обязательные обслуживание/максимальная автозаправка. На Шпицбергене (ENSB) на протяжении этих UTC-суток подтверждён полярный день. Однако после оборота в Новосибирске **нет допустимого следующего рейса среди 654 проверенных направлений**. Это контроль отдельного перелёта, исключённый из кандидатов первой миссии; безопасный прямой рейс не выполняет требование западного обхода.

Изменены пункты и дата по разрешению владельца. Более ранний старт вскоре после заката исследовался отдельно: прежнее условие «за час до восхода» не заменено молча. На всех 12 проверенных датах при прежнем часе старта нет первого хода в расширенном каталоге, даже с индивидуальным выбором всего допустимого начального топлива.

Допустимый интервал для первого прямого рейса — 27120.433…68485.433 кг; выбрано круглое значение с запасом до предельной посадочной массы, а не точка на границе. Максимальная автозаправка в Толмачёво остаётся обязательной. Склад UNNT первоначально 347000 кг; повторный визит не создаёт запас заново.

Отправление и прибытие занимают по 15 минут; после посадки 10 минут обслуживания, затем 5 минут организации заправки плюс перекачка по 800 кг/мин. Профиль B788-reference-v1 из #20 не изменялся: TAS 870.44 км/ч, 6.5 кг/км, 1800/200 кг на отправление/прибытие, резерв 5000 кг. Расход/нагрузка/наземные операции — опубликованные допущения, не AFM и не эксплуатационное разрешение. Численная точность поиска не означает такую же точность реального расписания.

## Полярный день, даты и границы поиска

Для ENSB проверяется весь интервал 00:00–24:00 UTC: общий интервальный решатель доказывает `-q < 0`, то есть Солнце непрерывно над геометрическим горизонтом. Это проверка конкретной точки на Шпицбергене, а не утверждение о всём севере. На всех выбранных датах до 21 августа включительно проверка проходит; 22 августа уже есть уход Солнца за горизонт.

Исследованы 21 июня, 15 июля, 1 и 10 августа, затем 15–22 августа 2026. Для прямого вечернего рейса с 65000 кг перебраны вылеты 16:00–20:00 UTC с шагом 1 минута. До 15 августа включительно на этой сетке безопасных полных переходов нет; 16 августа есть один, 20 августа — 19 (17:31–17:49 UTC), 21 августа — 24. **Это дискретные проверенные старты, не доказательство непрерывного окна всех возможных моментов вылета.** Каждый отдельный переход проверяется непрерывно по времени, а не солнечными отсчётами по минутам.

Для прежнего старта за час до восхода на каждой дате перебраны все геометрически отобранные первые направления. Для каждого рассчитан интервал законного начального топлива. Максимум даёт самый короткий обязательный оборот; если даже такой оптимистический префикс содержит Солнце, меньшая загрузка его не исправляет. Классификации и оставшиеся неопределённые случаи находятся в [dates.json](campaign-research/dates.json); в этих прогонах их нет. Этот результат ограничен каталогом, датами и моделью, не доказывает невозможность для любых мировых маршрутов.

## Продолжение и южные варианты

После выбранного прямого рейса все 654 другие геометрически отобранные площадки проверены из **фактического** состояния UNNT с полным баком и уменьшенным складом. В каждом следующем переходе найден солнечно опасный участок; у части есть также ограничения топлива/посадочной массы. Ожидание выключено, до рассвета мало времени. Объявлять эту посадку готовым началом непрерывной кампании нельзя. Детали: [continuation.json](campaign-research/continuation.json).

Рассмотрены первые рейсы в Сан-Паулу, Буэнос-Айрес, Монтевидео, Сантьяго, Кейптаун и Йоханнесбург при том же вечернем старте и индивидуальной законной начальной загрузке. Сан-Паулу проходит полный переход; остальные пять попадают на Солнце в полёте либо при обязательной заправке. Это пробы южных вариантов, не найденный маршрут через юг в Новосибирск. См. [southernProbes.json](campaign-research/southernProbes.json).

Отдельный [ограниченный поиск обходов](campaign-research/detours.json) охватывает весь расширенный каталог, включая южное полушарие, для вечерних стартов 21 июня 19:40, 15 июля 19:15 и 1 августа 18:30 UTC. Для каждого первого назначения взята одна загрузка `floor(максимум законного топлива)`; после первого полного оборота перебираются до 5 следующих рейсов, до 250 раскрытых состояний на первый ход, горизонт 4 суток от конца первого оборота. Получилось соответственно 237/257/302 допустимых первых рейса и 1139/2317/4491 раскрытых последующих состояний. Путей в UNNT нет; на этих трёх прогонах очереди исчерпаны без отсечения по указанным лимитам. Это не исключает другие даты, моменты вылета, начальные загрузки или новые аэропорты: особенно не доказана невозможность для всех топливных загрузок многопосадочного пути. Дополнительная проба четвёртой даты остановлена до завершения и в результат не включена.

Даже сам первый прямой рейс ещё не подтверждает интерес выбора последовательности промежуточных аэродромов. Поздний август почти завершает полярный день на Шпицбергене, поэтому может исчезнуть сюжетная необходимость долгой южной ветки. Эти вопросы остаются в #21 и #31. Для продолжения нужно исследовать другой маршрут/дату либо явно согласовать пересмотр эксплуатационных допущений/правил; не отключать массу или автозаправку ради сюжета.

Толмачёво не является Академгородком: наземная поездка/передача научных данных пока не смоделирована. Подтверждён только аэропортовый переход. ENSB с полосой 2318.918 м не проходит текущий фильтр B788 3000 м; будущие посадки там и в Антарктиде требуют #32. Полная [кампания и задачи](CAMPAIGN.md) пока являются планом.

## Данные и воспроизведение

[data/campaign](../data/campaign) содержит 1183 реальных аэропорта: все `large_airport` из pinned OurAirports плюс явный список, включая ULLI/UNNT/ENSB. 655 проходят фильтр открытой мощёной полосы 3000 × 45 м; 528 непроверенные. Это только геометрический отбор. Сохранены исходные ID, координаты, ВПП, лицензия Public Domain, commit `11e4de2834aff6ab54c1f8fc89b8679ea3d08418`, SHA-256 исходных CSV и дата получения. Включены южные регионы; произвольные координаты не добавлялись. Исходная классификация OurAirports относит UNNT к EU; расчёт использует реальные координаты, а не метку континента.

Новый каталог v2 и seed `academic-campaign-research-v1` отделены от исторического каталога/складов JFK. Профиль самолёта общий, без второй копии. Склады — конечные игровые числа, не реальные запасы аэропортов. Неизвестное покрытие полосы сохраняется пустой строкой и не проходит фильтр пригодности.

```sh
npm ci
npm run build
npm run validate:campaign-data
npm run research:campaign
npm run validate:campaign
# Необязательный более длительный поиск обходов (несколько минут):
npm run research:campaign-detours -- --verify
# Повторить получение и сверить данные:
python3 scripts/import-mission-airports.py --selection data/campaign/selection.json --output .build/campaign-import/airports.json
node scripts/campaign-data.mjs --write
git diff --exit-code -- data/campaign
```

Машинные части отчёта: [метаданные](campaign-research/report.json), [даты](campaign-research/dates.json), [свидетель](campaign-research/witness.json), продолжение и южные пробы по ссылкам выше. Состояния содержат ссылку на исходный файл складов и явные изменения; полный исходный склад не дублируется в каждом состоянии. SHA-256 входов, настройки и версии записаны. CLI повторяет вычисление, исполнение и проверку неизменности исходного состояния; `--verify` сравнивает все части сохранённого отчёта. Уточнение 0.5 → 0.05 с и интервала 900 → 300 с сохраняет безопасный результат и UTC окончания выбранного перехода. Контракт `after_turnaround` явно включает наземные фазы даже в цели; прежний JFK-контракт завершения по прибытию и его отчёт не изменены.
