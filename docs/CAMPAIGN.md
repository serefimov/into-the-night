# Предварительная кампания: три части знания

Предложение владельца от 2026-10-23 развивает игру после рецензии первого spike. Каркас записан в [#30](https://github.com/serefimov/into-the-night/issues/30); даты, маршруты, самолёт для полярных площадок и длительность получения данных ещё требуют проверки. Сюжет не объявляет всю цепочку проходимой.

| Этап | Сюжет и задача |
| --- | --- |
| Санкт-Петербург → Новосибирск | В Академгородке есть результаты борьбы с убийственным Солнцем, но они неполные. Первая часть знания. [#21](https://github.com/serefimov/into-the-night/issues/21) проверяет первый маршрут; [результат](FIRST_CHAPTER_FEASIBILITY.md) пока содержит вечерний кандидат с тупиком после заправки. |
| Япония | Японские учёные хранят вторую часть данных. [#31](https://github.com/serefimov/into-the-night/issues/31) проверяет путь из унаследованного состояния, время передачи и необходимость сезонного обхода. |
| Шпицберген пока недоступен из-за полярного дня | Третья часть находится на севере. Доступность определяется реальным Солнцем и полным маршрутом, а не искусственным запретом до определённой главы. Поздний старт первого этапа может изменить этот сюжет. |
| Южная полярная ночь | Убежище в Антарктиде, перелёты между станциями ради конечных запасов. [#32](https://github.com/serefimov/into-the-night/issues/32) проверяет реальные полосы и совместимость самолёта. [#25](https://github.com/serefimov/into-the-night/issues/25) возвращает длительное ожидание, [#33](https://github.com/serefimov/into-the-night/issues/33) — провизию. |
| Австралия и обратно на юг | За провизией приходится выходить из полярного убежища и возвращаться. [#34](https://github.com/serefimov/into-the-night/issues/34) проверяет всю сезонную цепочку с конечными складами, а не отдельные посадки. |
| Северная осень → Шпицберген → бункер | Безопасное окно на севере, третья часть знания, затем финальный путь. [#35](https://github.com/serefimov/into-the-night/issues/35). Место бункера и способ защиты ещё не определены. |

Северная осень — это южная весна: полярная ночь в Антарктиде заканчивается, нельзя «ждать осени» без указания полушария/UTC. Знания не включают скрытую неуязвимость. Академгородок, лаборатория и бункер не подменяются точками аэропортов: передача на месте или наземный этап должны иметь явное время и проверку Солнца.

Сначала #21 и простой первый playable-этап #22–#24 с рецензией владельца. Там остаются карта/глобус, карточка аэропорта, одна кнопка «Полёт», максимальная автозаправка, **без еды и ручного ожидания**. Сезонное расширение позже получает новые версии состояния/сохранений, ожидание и провизию; не возвращает прежнюю панель ручных операций. Три части знания и текущая цель сохраняются, повторное посещение не дублирует прогресс.

Следующая точка решения — полноценный первый сценарий. Прямой вечерний Пулково → Толмачёво подтверждён до конца оборота, но даёт 0 следующих ходов в исследованном каталоге; его недостаточно для кампании и для проверки интереса последовательностей посадок. Физика имеет приоритет: дальнейшие задачи сначала дают численный свидетель или честные границы поиска, затем реализацию. PR вливает только владелец.
